## 🚀 Live Interactive Lab Hub (`main.html` / `index.html`)

This repository contains a **built-in interactive preview portal** (`main.html` / `index.html`) ready for deployment on **Vercel** or any static web host.

### ✨ How to Use the Lab Hub:
1. **Open the Portal**: Open `main.html` (or `index.html`) in any browser or visit the deployed Vercel URL.
2. **Select Files**:
   - **Quick Dropdown**: Use the top dropdown selector to switch between any assignment (`f1` through `f12`).
   - **Interactive Sidebar**: Click any file in the left sidebar list with search and filtering.
   - **"All Previews" Mode**: Toggle the view mode to see all live previews side-by-side in a responsive grid.
3. **Device Testing**: Toggle between **Desktop**, **Tablet (768px)**, and **Mobile (390px)** viewport sizes to test responsive layouts.
4. **Direct Open**: Click **"Open Tab ↗"** to test any assignment independently in a standalone tab.

## 🌐 Deploy to Vercel

1. Push this repository to GitHub.
2. Import `roshandhiman/FEE-G4-0311` into [Vercel](https://vercel.com).
3. Deploy as a **Static Site** (no build command needed).
4. The root `index.html` / `main.html` will immediately serve the full interactive lab hub.
